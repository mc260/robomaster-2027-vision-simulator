## 公式与处理

令当前血量为H，损失血量为Δ：

```text
Δ = 10000 − H
λ = 1 − Δ / 20000
总像素数 = (1920 × 1080) × λ²
```

保持长宽比、均匀缩放时，宽高分别乘λ：`round(1920λ) × round(1080λ)`。采用面积平均降采样，再以双线性插值放大回基准画布。程序控件位于此处理区域之外。

```cpp
cv::resize(baseline, reduced, reducedSize, 0, 0, cv::INTER_AREA);
cv::resize(reduced, result, baseline.size(), 0, 0, cv::INTER_LINEAR);
```

尺寸四舍五入会产生小范围平台，例如9995～10000血量均得到1920×1080，这不表示滑块没有生效。

## 显示缩放与规则处理分开

默认自适应模式会将处理后的1920×1080再放入窗口，显示层平滑缩放可能减弱可见差异。

1:1模式下，一图像像素对应一屏幕物理像素，显示层不增加平滑缩放。设备像素比用于适配高DPI；大图用滚动条查看。自动测试在设备像素比1和2下比较实际绘制像素。

“原始画面”是等比例适配并补黑边后的1920×1080基准图，未进行血量降质，方便在同视野下比较。

## 模拟范围

输入不足1080p时先放大到规则基准，无法恢复输入缺失的细节；非16:9输入补黑边。本程序实现分辨率与重采样机制，没有复现官方图传编码、码率、网络延迟、丢包或完整选手端UI，也没有接入裁判系统自动读取基地血量。实际比赛以组委会最新规则及设备实现为准。
